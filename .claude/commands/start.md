# #start — Sessiyani boshlash

Har yangi sessiyada quyidagilarni bajar:

## 1. Kontekstni o'qi
- ~/.claude/agents/_domain.md — loyiha tafsilotlari
- PROJECT_CONTEXT.md (mavjud bo'lsa) — so'nggi sessiyalar tarixi
- .claude/rules.md (mavjud bo'lsa) — loyiha qoidalari

## 2. Git holatini tekshir
git log --oneline -8
git status

## 3. Loyihani skanla
Kechagi commitlar nima o'zgartirgan? (git log --since="yesterday")
Ochiq muammolar bormi? (project_problems.txt yoki ISSUES.md)

## 4. Tayyorlik hisobot
Qisqacha: so'nggi o'zgarish, joriy holat, keyingi qilish kerak bo'lgan ish.
